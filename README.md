## 📖 Обзор

Rule34 WebApp — это быстрый и современный веб-клиент на базе **Flask Async** и **Hypercorn**, который обеспечивает комфортный просмотр и поиск контента. Помимо удобного премиального интерфейса (Glassmorphism), приложение работает как прокси-сервер для обхода локальных блокировок провайдеров (ISP) и CORS, обеспечивая бесперебойную загрузку изображений и видео как в браузере, так и для мобильных клиентов.

## ✨ Ключевые возможности

### 🖼️ Просмотр контента
- **Адаптивная сетка (Masonry):** Каскадная сетка элементов, идеально подстраивающаяся под десктопные и мобильные экраны.
- **Поддержка Видео и Изображений:** Нативный встроенный видеоплеер и удобный кастомный Lightbox для полноэкранного просмотра.
- **Премиальный интерфейс:** Глубокая темная тема, эффекты стекла (glassmorphism) и плавные CSS3 градиенты.

### 🔍 Поиск и навигация
- **Продвинутый поиск:** Умные подсказки тегов в реальном времени (через API) прямо во время ввода.
- **История поиска:** Сохранение в сессии недавних поисковых запросов для быстрого доступа в один клик.
- **Сортировка:** Поддержка сортировки по дате, рейтингу (score), а также "Случайный" (Random) режим без перезагрузки всей логики.

### 💾 Управление данными
- **Избранное:** Сохраняйте любимые посты в локальную базу данных SQLite. Уникализация "лайков" построена на основе IP-адресов пользователей.
- **Молниеносное кэширование:** Глубокая интеграция с **Redis** для кэширования результатов API-запросов, что многократно снижает нагрузку и ускоряет ответ.

### 🛡 Обход блокировок и Проксирование
- **Proxy-эндпоинты:** Специальные роуты `/proxy/image` и `/proxy/video`, работающие через асинхронный `httpx`, позволяют пользователям загружать контент, даже если оригинальные CDN заблокированы в РФ.
- **Отвязка от системных прокси:** Встроенная защита `trust_env=False` для стабильной работы локально (при включенных VPN) и на сервере.

## 🛠 Стек технологий

- **Язык:** Python `3.11+`
- **Web-Фреймворк:** Flask (Async) `^3.1.3`
- **Сервер:** Hypercorn `^0.18.0` / Uvicorn (для локальной разработки)
- **Сеть:** httpx `^0.28.1`
- **База данных (ORM):** Flask-SQLAlchemy `^3.1.1` (SQLite)
- **Кэширование:** Redis `^8.0.1`, Flask-Caching `^2.4.0`
- **Frontend интерфейс:** HTML5, Vanilla CSS3, Bootstrap 5, Awesomplete

## 🚀 Установка и запуск

### Требования
- Python **3.11** или выше
- Redis (опционально для локальной разработки, обязательно для продакшена)

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd rule34_app/rule34-webapp
```

### 2. Создание виртуального окружения
```bash
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
# Установка пакетов для разработки и тестирования
pip install -r requirements-dev.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` в корне проекта на основе доступных настроек:
```env
# URL для Redis (по умолчанию используется SimpleCache, если оставить пустым)
CACHE_REDIS_URL=redis://localhost:6379/0
# Порт для запуска приложения
PORT=8080
```

### 5. Запуск приложения
```bash
# Запуск через встроенный скрипт
python run.py
```
*Приложение будет доступно по адресу `http://localhost:8080`*

## 🏗 Архитектура

Проект построен по модульной архитектуре (Flask Blueprints), что упрощает его поддержку и масштабирование:

```text
rule34-webapp/
├── project/
│   ├── api/          # Роуты для автокомплита тегов
│   ├── gallery/      # Основная логика работы с API Rule34 и проксирование
│   ├── main/         # Главная страница
│   ├── templates/    # HTML-шаблоны (Jinja2) с интерфейсом Glassmorphism
│   ├── static/       # Иконки, кастомные статические файлы
│   ├── extensions.py # Инициализация db, cache
│   └── models.py     # SQLAlchemy Модели (Favorite)
├── run.py            # Точка входа ASGI (Hypercorn)
├── requirements.txt  # Зависимости продакшена
└── requirements-dev.txt # Зависимости для локальной разработки
```

## ⚙️ Деплой (Render.com)

Проект изначально оптимизирован для бесплатного/платного хостинга на **Render**:
- В качестве Web Service используется `Hypercorn` для поддержки ASGI и асинхронного Flask.
- База данных SQLite сохраняется временно (эфемерный диск) или на смонтированном диске (Persistent Disk) Render.
- Настроен обход `X-Forwarded-For` для точного получения реального IP пользователя через внутренний балансировщик Render.
